## Email Marketing Service
Этот проект представляет собой систему управления массовыми рассылками email-ов, включающую управление клиентами, сообщениями, рассылками, а также расширенные функции аутентификации, статистики и прав доступа.

### Обзор
Данный сервис предназначен для автоматизации и управления массовыми email-рассылками. Он позволяет создавать и управлять клиентами, шаблонами сообщений, планировать рассылки, отслеживать их успешность и управлять доступами пользователей.

## Основные возможности
Управление клиентами (добавление, редактирование, просмотр, удаление)
<br>Создание и редактирование сообщений (темы и тела)
<br>Планирование и управление рассылками (статусы: создана, запущена, завершена)
<br>Отправка рассылок вручную через интерфейс или командную строку
<br>Отслеживание попыток отправки с логами
<br>Регистрация и аутентификация пользователей с подтверждением email
<br>Восстановление пароля
<br>Статистика по рассылкам и попыткам
<br>Роли и права доступа (пользователь, менеджер)
<br>Кеширование для повышения производительности
<br>Установка и запуск<br>

### <br> Клонируйте репозиторий:

````
git clone https://github.com/Nurlan-Grachyov/DjangoCourse.git
cd DjangoCourse
````

### Настройте виртуальное окружение и установите зависимости:

````
poetry install
````

### Настройте параметры базы данных и почтового сервера в файле конфигурации.

__Примените миграции:__
````
python manage.py migrate
````

__Создайте суперпользователя:__
````
python manage.py createsuperuser
````

__Запустите сервер:__
````
python manage.py runserver
````
### Использование
Административный интерфейс доступен по адресу: http://localhost:8000/admin
<br>После регистрации и входа пользователь сможет управлять своими клиентами, сообщениеями и рассылками.

Для запуска рассылки вручную используйте интерфейс или командную строку командой:
````
python manage.py send_email
````

### Административные функции
Управление клиентами, сообщениями и рассылками через административный интерфейс.
<br>Просмотр логов попыток отправки.
<br>Управление пользователями и ролями.
<br>Авторизация и безопасность
<br>Регистрация с подтверждением email
<br>Восстановление пароля
<br>Разграничение прав доступа:
<br>Пользователь: управляет только своими данными
<br>Менеджер: просматривает все, управлять чужими данными не может
<br>Внедрение защиты от несанкционированного доступа и CSRF
<br>Дополнительные функции
<br>Статистика по успешным и неуспешным попыткам
<br>Ограничение доступа к данным в зависимости от роли
<br>Настройка серверного и клиентского кеширования для ускорения работы
